降世神通：最後的氣宗將於2025年11月14日舉行售前賽活動，想更了解單卡在限制賽的單卡評分與建議嗎？那就來看看這一系列的TLA限制賽介紹吧！

  • 機制介紹請看這篇：降世神通機制解析

色組主題

基本上，這個系列的色組主題，是由一張混血法力的雙色C卡生物、一張該色組的多色U卡、以及一張混血法力的U卡傳奇生物所構成。讓我們來看看吧！

本次色組主題新增Takeaway連結，希望能幫助讀者進一步理解色組的重點、以及發展的可能性

Takeaway：A → B → C → D
A：基礎特徵 — Who we are?
B：色組主題 — How we stand?
C：主題回報 — What we want?
D：延伸發展 — Where we go?

白藍 — 飛兵（Flyers）

C卡的 Cat-Owl 看似普通的飛兵，但其重置的異能除了讓生物能進行阻擋外，也能支援截水神通（Waterbend）；U卡的 Air Nomad Legacy 除了讓你全家飛兵變大外，派出的線索也能讓你抽牌。而另一張 Sokka, Lateral Strategist 只要與另一隻生物一同攻擊就能抽牌，若是色組主打的飛行生物，更有機會持續攻擊並拉開資源差距。

Takeaway：飛行生物 + 警戒 → 飛兵增益 → 獲得更多資源、手牌 → 截水神通

藍白色組曲線偏重，單體夠強但策略上較為線性，因此需要強力的終端來提高套牌上限，色組R卡不論是 Aang, Swift Savior 、或 Katara, Water Tribe's Hope 都相當強力，截水神通的異能更能引爆場面優勢。

藍黑 — 抽二（Draw Two）

C卡的 Messenger Hawk 自帶線索（Clue）衍生物，可以主動支援一次抽二的效果，本身的進攻能力也相當可觀。 U卡的 Foggy Swamp Spirit Keeper 則是抽二主題的回報單卡，每回合抽第二張時都能派出一張1/1無色的精靈衍生物，具有有條件性的穿透力可以幫助你偷打一些傷害。而另一張 Hama, the Bloodbender 的異能則隱含著降世神通故事中罕見的截血神通（Bloodbend），截血神通脫胎自截水神通，能操縱他人體內的血與水，也因此這張牌的效果也是以截水神通來發動。

Takeaway：派出線索 → 抽二主題 → 派出更多小生物 → 截水神通

黑紅 — 烈火國快攻（Fire Nation Aggro）

C卡的 Vindictive Warden 單卡直接把黑紅色組的關鍵字都寫了上去：威懾（Menace）讓他具有一定程度的穿透力、攻擊後存活機率提高；而攻擊觸發振火神通（Firebending）增加的紅色法術力，還可以用來支付起動式異能的費用。U卡的 Cruel Administrator 的突擊（Raid）則受益於威懾異能的鋪墊，而當他攻擊時，派出的衍生物又能繼續增強振火神通所能增加的法術力。而另一張 Zhao, Ruthless Admiral ，除了本身具有振火神通外，更暗示你與白黑的犧牲主題的搭配，將能讓你獲得更好的報酬。

Takeaway：具有〔振火神通 / 威懾 / 起動式異能〕的生物 → 進攻（突擊、觸發振火神通）→ 派出更多具有振火神通的生物 → 犧牲永久物（尤其是生物、神器）來獲得回報（白黑）

紅綠 — 運土跳費（Earth Rumble Ramp）

不管是運土神通（Earthbend）派出的地生物、或是地牌進場（地落，Landfall），都能讓C卡的 Earth Rumble Wrestlers 滿足攻擊力4的條件，同時獲得綠色中大型生物最重要的踐踏（Trample）異能。 U卡的 Bitter Work 則讓紅綠色組不但生物大隻、還很會賺牌！竭絕（Exhaust）雖然僅能用一次，但運土神通4造出的4/4地生物更可讓這個賺牌的循環持續運行。而另一張 Uncle Iroh 的振火神通、與課程（Lesson）減費施放的效果，更有助於施放瞬間的課程牌。

Takeaway：關注地生物 + 地落 → 關注攻擊力4以上 → 運土神通 → 更多的費用（振火神通） + 與課程牌的互動（綠藍、藍紅）

綠白 — 伙伴（Allies）

C卡的 Earth Kingdom Soldier 的生物類別竟然沒有伙伴！？而放豆（+1/+1指示物）的效果看起來更適合黑綠色組 Not elegant!!! 。U卡的 White Lotus Reinforcements 則簡單暴力，是伙伴們的輝煌的讚美詩。而伙伴不夠怎麼辦呢？就靠另一張 Suki, Kyoshi Warrior 不斷進攻來呼朋引伴吧！

Takeaway：放豆（+1/+1指示物） → 伙伴主題 → 伙伴增益效果 → 關注生物（伙伴）數量 + 派出更多的伙伴（紅白）

由於綠白色組的混血C卡實在太不給力，這邊必須提一下另一張綠色的U卡傳奇 Haru, Hidden Talent ，這張就是扎實的伙伴主題的回報，每當有一個伙伴進場就能運土神通1，也讓 Suki, Kyoshi Warrior 每次攻擊都能至多加2攻，輪抽時別忘了一起拿下他們！

白黑 — 犧牲（Sacrifice）

C卡的 Pretending Poxbearers 可一魚二吃。U卡的 Tolls of War 則是犧牲主題的重大回報單卡，除了主動派出一個線索來滿足第二條派出伙伴的效果外，也仰賴更多主動犧牲的引擎來滾雪球。而另一張 Hei Bai, Spirit of Balance 就是這個色組需要的犧牲引擎。

Takeaway：犧牲用的肥料 → 犧牲主題 → 主動犧牲源（如線索）+ 派出更多肥料 → 犧牲引擎 + 獎勵犧牲、或離場的額外回報

白色的截氣神通（Airbend）也能主動觸發我方生物離場

藍紅 — 戰鬥課程（Combat Lessons）

C卡的 Abandon Attachments 本身是就是課程牌，棄一抽二的效果更可以加速課程牌填墳的效率。U卡的 Dragonfly Swarm 則鼓勵你放越多的課程或非生物牌，並早早將它們放入墳場來增強他的攻擊力、並獲得死去的回報。而另一張 Professor Zei, Anthropologist 除了作為濾牌的引擎外，有需要的話也可以犧牲他來重複利用墳場中的瞬間/巫術牌。此外，兩張混血牌也都具有多抽牌的能力，也很適合在藍黑的抽二主題中使用。

Takeaway：課程 + 棄牌 + 抽二 → 關注墳場有無課程（瞬間/巫術、或非生物）牌 → 因墳場的課程牌獲得回報 → 重複利用墳場中的課程（瞬間/巫術牌）

混血牌的抽二效果也是藍黑色組很需要的，輪抽時這兩個色組要打架了XD

黑綠 — 豆豆（+1/+1 Counters）

這邊的+1/+1 counters真的不知道怎麼翻，直翻「+1/+1指示物」太無聊，因此我就用限制賽文章常用的敘述 — 放豆，用「豆豆」作為主題名稱，希望讀者能喜歡。

C卡的 Earth Village Ruffians 一臉肥料樣，在白黑犧牲主題中應該也很適合。U卡的 Dai Li Agents 進場可以撒豆成兵，連續兩次的運土神通1可以讓場面多2隻身上有豆的生物，並在後續戰鬥獲取更大的優勢。而另一張 Long Feng, Grand Secretariat 就更厲害了，每次的生物或地牌從戰場進入墳場時，都能繼續放豆，有他在就能讓黑綠豆豆的主題轉到停不下來。

Takeaway：生物/地死去 + 運土神通 → 關注+1/+1指示物 → 增加身上有+1/+1指示物的生物來獲得回報 → 疊加前面三項，把雪球滾更大！

紅白 — 鋪場快攻（Go Wide Aggro）

C卡的 Wandering Musicians 體格優秀，攻擊時可以強化全家生物。U卡的 Sun Warriors 可以善用他振火神通的異能，派出更多的伙伴。而另一張 Jet, Freedom Fighter 則受益於生物數量，除了作為去除外，死去後也能繼續增強隊友。

Takeaway：攻擊時增益 → 鋪場 → 增加生物數量而獲得回報 → 鼓勵進攻與交換來賺取額外價值

綠藍 — 跳費 + 課程 （Ramp + Lessons）

C卡的 Platypus-Bear 除了自磨（Mill）兩張以外，本身的體格也適合阻擋，可幫助跳費套牌度過前期。U卡的 Hermitic Herbalist 除了是優秀的加速人以外，更可以幫助你更輕易地施放課程牌；而另一張 Guru Pathik 則能進一步讓你把課程牌放入手中，並且因施放而獲得回報，更延伸到傳記（Saga）、以及祭祠（Shrine）這兩個次主題。

Takeaway：自磨 → 跳費 + 課程 → 更多的課程（傳記、與祭祠） → 施放課程（傳記、與祭祠）並收穫回報

混血法術力賦予限制賽更多的可能

十種雙色色組是一個協助玩家快速上手限制賽的訊號（Signal），但不代表這就只是限制賽的全部，而本次降世神通使用到混血法術力（Hybrid Mana）的設計，更讓這個套牌搭配的可玩性大幅提升！我們知道，對於某雙色色組而言，使用到該色組中的其中一種顏色，搭配上另一個顏色，仍另有6種色組的可能。在組牌或輪抽時，別忘了把這些可能性一起納入考量喔！

以白黑色組為例，使用到白色的其他色組有白藍、綠白、以及紅白這3種；而使用到黑色的其他色組則有藍黑、黑紅、以及黑綠這3種，總共有7種變化（若再算上純白、與純黑，光兩色以內就有9種可能）。要方便記憶的話，就去看不含該雙色的三色色組，而這三色中可以衍伸出另外3種雙色色組，10減3即可得知有7種雙色的可能組合。（如不含白黑的三色色組是鐵木爾（扣掉綠藍、藍紅、與紅綠））

評分標準

5.0：無條件必拿，能帶來幾近勝利的優勢
4.5：色組正確無條件必拿，能帶來大幅的優勢
4.0：有首選價值，與色組主題的相性極佳，能成為混色／轉色或進入色組的決定性牌張
3.5：系列頂 U、C 與其他強度夠的單卡，與色組主題相性佳，能成為進入色組的關鍵牌張
3.0：色組主題的重要單卡，以及其他高於平均值的單卡，會希望進到最終牌組
2.5：平均水準，通常是不錯的曲線填充物
2.0～1.0：低於平均，基本傾向不放，必要時可用來填充，但不宜過多
0.5～0.0：不可用，基本上別放，放了只會幫你輸

結語

這次降世神通重新回歸十個雙色主題，在預覽的過程中竟讓我有眼睛一亮的感覺！不論是限制賽的可玩性、構築賽的開發潛力、或是這個IP的故事、以及其深蘊的內涵等；雖然我對降世神通並不熟悉，但這次的設計除了讓我期待限制賽外，更讓我想進一步了解更多這個IP。我想，透過深入淺出，將各IP獨特的元素、風貌、以及彩蛋等揉合進MTG的機制與遊戲性中，這是一種極耗費心力的二次創作，而我必須說這次威世智設計團隊真的把TLA主系列打造得非常棒（不含TLE）！而透過這樣的連結，讓MTG玩家、與該IP的既有受眾對彼此感到有興趣，這將是一個雙贏的合作。我想，無疆宇宙（Univere Beyond, UB）的初衷應該是要達到這樣的目標，而不是讓兩個群體都因此感到失望。

以上所說的，如果不實際玩過限制賽你是無法完整體驗到的。所以說啦，這週末約上好久不見的朋友，一起來體驗降世神通限制賽的魅力吧！

上面的感想寫於 Avatar Succeeds Where Spider-Man FAILED as a Magic: The Gathering Set 這部影片發布之前，很榮幸地我對本次的降世神通限制賽與 Tolarian Community College 有著高度類似的評價；也希望威世智對於UB的發展策略，能在2027年起轉用一種永續、雙贏的方式來經營。
