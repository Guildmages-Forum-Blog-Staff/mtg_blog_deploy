  1. 以下的更新內容，著重在CU卡實測的體感，樣本數沒有很多，大家可以測試看看再一起討論！
  2. 本文發布於SOS上市後第一週，後續的限制賽仍會持續變化，而這也是限制賽的迷人之處。

更新五學院的核心遊戲計畫

先說結論：當這五張U卡傳奇在場時，若你能感覺到優勢不斷擴大的話，那恭喜你，你的套牌組/抽對了！

  • 白黑銀毫：
    • 連辭 快攻 — 灌大我方/去除敵方生物、並靠連辭機制滾起強大的場面優勢。傳統的生物 + 戰鬥詭計的遊戲計畫，在白黑色組中仍十分有效；然而，這種牌型對於牌序是否正確要求很高，建議在輪抽時再選擇。
  • 藍紅粹麗：
    • 咒語 快攻 — 低費咒語觸發多次炫示，靠 Expressive Firedancer 能打出成噸的傷害。
    • 跳費 中速 （多為一次性）— 以 Sanar, Unfinished Genius 為核心，依靠珍寶、或其他跳費手段來完整解鎖炫示牌的最大回報（五費或更多施放咒語）。 Abstract Paintmage 在此路線格外重要。
  • 黑綠靡華：
    • 補血 強攻 — 以 Bogwater Lumaret 為啟動核心，搭配像 Pest Mascot 這類回報牌的線性強攻計畫。
    • 輸注 中速 — 以 Lluwen, Exchange Student 來派出1/1害蟲鋪場、穩定補血來最大化輸注牌的效益。
    • 墳場 控制 — 以 Cheerful Osteomancer 為核心，使用大量高攻低防的生物進行交換，並在中期反覆回收墳場中的生物，來達成獲勝的必然性。
  • 紅白衡鑑：
    • 離墳 強攻 — 穩定離墳，搭配 Kirol, History Buff 來強化生物體格。
    • 返照 控制 — 與黑綠的墳場計畫是重複利用生物不同，紅白更擅長於前中期累積墳場資源，並有效利用返照咒語來讓你在後期勝出。
  • 綠藍量析：
    • 跳費 控制 — 如 Tam, Observant Sequencer 牌張設計的指示：持續下地、並穩定滾起對手追不上的資源。本遊戲計畫的發力點將在五六塊地的後期，亟需前期生存的能力。而跳費咒語能讓你提早進入這個守備範圍，相當重要。
    • 遞增中速 — 陷阱思路，這個系列沒有慢到能等你拍一堆前期虧體質的生物，中後期再慢慢長大來收頭。

綠藍量析（Quandrix）學院的自我矛盾

1. 矛盾一：生存與成長的悖論
延續上一章節所說的，綠藍色組本系列的強項應為跳費控制，扛住前期並於後期致勝。然而，色組生物主題的遞增（Increment），卻是要先虧體質再獲取增長，這是個顯著的邏輯矛盾，因此我們能辨識出遞增生物可能是陷阱思路的訊號。而接下來，我們用這一張牌來解釋。

U卡的 Fractal Tender 除了登場那回合幾乎無作用外，在你後續沒有四費以上咒語、或主動放豆的方式，他幾乎是一張不可用的五費3/3。而其他大部分的遞增CU生物都是先虧體質，然後需至少結算一至兩次遞增才能勉強補回來。若沒有特別留意去抓取飛兵、或跳費後的大招、節奏扭轉牌，綠藍很容易在生物排排站的狀況下打成和局、或單方面被對手的飛兵推死。

另一方面，像 Fractal Mascot 、 Paradox Surveyor 這樣的牌，才是綠藍色組需要提早拿下的牌。前者進場Stun + 6/6踐踏的體格，不考慮大逆風的極端狀況，基本上他進場就等於讓對手的攻勢暫停一回合，而6/6踐踏也是反打的致勝手段。至於後者，3/3延勢的體格前期能守住血線，且ETB在前中後期都能找到最適合的牌。

但還是要稍微幫遞增機制平反一下， Tester of the Tangential 就是U卡中少數值得使用的遞增生物，除了支援綠藍色組外，他在藍紅色組的表現也相當不錯！搭配低費的咒語與另一隻生物如 Elemental Mascot ，每個戰階開始把豆子移過去，接下來的二費以上咒語都能再讓他把豆放回來。在藍紅色組中，是張維持節奏優勢（低費咒語互動）同時加強場面（移豆增強體質）的好牌。

2. 矛盾二：魔法力曲線的誤導
遞增機制的設計，會誘惑玩家在套牌中塞入較高費的咒語去增加觸發的頻率，但同時也會導致套牌曲線偏高，有機會惡化成卡手的問題。要能有效地運用強力的高費咒語，關鍵仍在於用跳費手段去跨過這個門檻，而不是靠遞增生物慢慢磨蹭。

簡而言之，遞增機制本質需要成長時間，但這與綠藍擅長的跳費控制的策略相斥（遞增生物通常無法在前期擔任好阻擋者的角色）。若我們輪抽時要進入綠藍色組，關注的重點應是有無跳費相關的牌張，而不是因為持續傳來遞增生物，反而認定綠藍色組是開放的。

防禦力4很重要！

在這個環境中，存在著許多防禦力4或以上的高防低攻生物。它們的存在定義著以下幾件事：

  • 4攻（或能主動成長到4攻）的地面生物表現將落差極大。例如 Rehearsed Debater 與 Imperious Inkmage 這兩隻生物乍看下相差無幾，但他們在面對 Rubble Rouser 這樣的阻擋生物時，進攻強度將天差地遠。
  • 單純打生物3、或-3/-3以下的去除強度偏弱 ，如 Impractical Joke 或 Last Gasp 。
  • 無成長異能、或ETB普通的二費生物，隨著回合數遞進，越晚抽上手越差。如許多黑綠色組中的熊。

而要對抗這個限制，我們可以調整策略如下：

  • 使用X費的生物或去除，可以增加不同時期的彈性。
  • 選用可以打4傷、或-4/-4以上的去除，如 Unsubtle Mockery 、或秘典中的 Dismember 。
  • 重質不重量的生物選擇，與其打快攻，不如靠去除/康撐過前期，主力往三四費後去經營，穩定性應該會更好（尤其在黑綠色組）。
  • 即使打快攻，選擇生物時也要將4防生物的門檻放在心上，並做對應的選牌。

及時的去除/康牌變更好了！且通常會帶來節奏的反轉

這個系列的生物/咒語比例，通常會比其他系列的更「均衡」一點。與其增加生物的密度，單兵 + 咒語滾雪球通常更有效率，而這在白黑/紅藍色組的快攻計畫更是如此。

正是如此，跟其他限制賽相比，濫康或濫殺的遊戲計畫效果會更好。準時的康或去除解掉對手的關鍵生物，往往會帶來節奏的反轉，即使是巫術時機的去除也通常能達到這樣的效果。

矛與盾：白底快攻與藍色回手

紅白與黑白都擅長在生物上放豆增加體格並進攻，但這類的進攻維度，容易因為一張回手就讓攻勢大幅衰退。藍紅色組擅長從回手後取得節奏優勢，因此像 Matterbending Mage 這類的牌將更適合藍紅使用。而綠藍色組若前期防線不足，單純的回手可能只是拖慢一回合，因此需要搭配生物來一併使用；或是使用 Proctor's Gaze 來干擾對手節奏，並使自己跳費向前。

需留意掃場咒語

秘典牌中的白藍兩張超載（Overload）咒語都視同單向掃場，而紅色的 Subterranean Tremors 基本上也能發揮一桿清檯的能力。 Brotherhood's End 的全場打3雖範圍較小，但仍是有效的中期掃場、至於 Culling Ritual 只能掃2費以下就比較尷尬，只有在面對極限的白黑快攻、或以 X/X Fractal tokens為主力的綠藍中才可能有好表現，但備牌局中如果你是上述這兩類、或會被掃2費懲罰的牌型，還是要意識到有這張牌的存在。

而主系列中這兩張牌也接近掃場咒語的強度，尤其是黑白的 Moment of Reckoning 幾乎是單向掃場 + 場面優勢大幅擴大，一結算通常就能顛覆戰局。即使對手地牌缺少施放它的其中一個顏色，只要場上有珍寶、或有機會轉出其他顏色的牌，都需要稍加注意。而沒有提 Artistic Process 的原因是：如果你的套牌會被五費時的全場掃二懲罰，那很可能是你組錯了。

結語

SOS限制賽明明只有五個色組，但玩起來卻讓我有超過10種主題的感覺，而我甚至還沒有討論到三色以上聚輝的可能性！在加入了秘典牌SOA後，也讓咒語的互動維度大幅上升。這個系列的玩法上相當多變，值得大家多揪輪抽一起研究，相信仍有許多本文未提到的玩法有待開發！

讓我們一起進入心流，掌握秘典的最佳使用方式吧！
